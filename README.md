# OtoShot

PCで鳴った直前の音を、ショートカットひとつでWAVとしてコピーする Windows アプリです。録音していなくても、さかのぼれます。

- ホームページ・使い方: https://yoruhinot.github.io/OtoShot/
- Microsoft Store: https://apps.microsoft.com/detail/9PC6K8VJ1F4B
- インストーラー: このリポジトリの [Releases](https://github.com/yoruhinot/OtoShot-releases/releases/latest)

このリポジトリは配布専用です。ソースコードは公開していません。

- Windows 10（2004以降）/ 11、64bit 向けです。インストーラー版は電子署名がないため、インストール時や初回起動時に Windows の警告が出る場合があります（Microsoft Store 版では出ません）。
- 通信はしません。クリップはこのPCにだけ保存します。
- 通話中は相手の声も入ります。クリップを人に聞かせる前に、相手にひとこと伝えてください。
- ライセンスと第三者ソフトウェアの表記は、インストーラーに同梱しています。ホームページの「ライセンス」でも確認できます。
- 不具合の連絡は X [@yoruhinot](https://x.com/yoruhinot) まで。

---

OtoShot copies the last few seconds of your PC's sound as a WAV, with one shortcut. Windows app. You can rewind to it even if you weren't recording.

- Homepage and guide: https://yoruhinot.github.io/OtoShot/en/
- Microsoft Store: https://apps.microsoft.com/detail/9PC6K8VJ1F4B
- Installer: [Releases](https://github.com/yoruhinot/OtoShot-releases/releases/latest)

This repository only distributes the installer. The source code is not public.

- For Windows 10 (2004 or later) / 11, 64-bit. The installer is not code-signed, so Windows may show a warning during installation or first launch (the Microsoft Store version does not).
- No network connections. Clips stay on this PC.
- During a call, the other people's voices are captured too. Let them know before you share a clip.
